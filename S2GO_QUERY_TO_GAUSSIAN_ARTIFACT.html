四个最容易误解的地方

读图时要把“高层局部状态”和“最终实例”区分开。

不是 one query = one object

一条 query 可能只覆盖物体局部，也可能表示道路、墙面等 stuff 区域。

是 one query = one local bundle

children 共享父语义、速度和整体存在 gate，形成局部结构先验。

Opacity 不是 objectness

它只表示 primitive 对占据/渲染的存在贡献，不能直接判定 instance 或 OOD。

Child 不做昂贵 Transformer

论文的效率来自 parent-level compression，再用 decoder 批量输出 child 参数。

论文明确给出了 parent/child 属性分解与 Gaussian 组合公式；截至整理时没有可用的官方源码，因此具体 MLP 层数、激活函数和 tensor packing 不应凭空补全。
